# architecture-propdevelopment

Проектная работа спринта 5: подготовка строительной компании PropDevelopment к комплексному аудиту безопасности.

| Директория | Содержание |
|---|---|
| [Task1](Task1) | Mindmap классификации данных (ISO/IEC 27001/27002) и оценки рисков |
| [Task2](Task2) | Проверочный лист безопасности для бизнес-систем |
| [Task3](Task3) | Внешние интеграции «Умный дом»: C4-диаграммы контекста и контейнеров, требования к интеграциям |
| [Task4](Task4) | RBAC в Kubernetes: таблица ролей, скрипты создания пользователей, ролей и привязок |
| [Task5](Task5) | Сетевые политики Kubernetes для изоляции трафика между сервисами |

Диаграммы хранятся в формате draw.io (`.drawio`, открываются в [app.diagrams.net](https://app.diagrams.net)), для удобства просмотра рядом лежат PNG.
